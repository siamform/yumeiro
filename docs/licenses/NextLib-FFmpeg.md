# NextLib and FFmpeg

Yumeiro bundles **NextLib** (`io.github.anilbeesetti:nextlib-media3ext`, https://github.com/anilbeesetti/nextlib)
for its FFmpeg audio decoders.

- NextLib: GNU General Public License v3.0 — same license as Yumeiro (full text: `/LICENSE`).
- FFmpeg (https://ffmpeg.org), built into NextLib's native libraries: LGPL-2.1-or-later, with GPL-licensed parts
  enabled, so the combination is distributed under GPL-3.0. Source: https://github.com/anilbeesetti/nextlib and
  https://ffmpeg.org/download.html.

Only the arm64-v8a and armeabi-v7a libraries ship in the APK.
