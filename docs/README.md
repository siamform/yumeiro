Internal working notes (agent handover logs, owner task lists, the bug/fix ledgers, release plans, status reports and
research notes) were moved out of this repository on 2026-11-25. Older commits and some code comments still name
files such as `docs/HANDOVER.md` or `docs/BUGS-AND-FIXES-2.0.0.md`; those files are in the git history and in the
maintainers' private archive, not in the current tree.
